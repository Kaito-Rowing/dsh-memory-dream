# dsh-memory-dream v0.3.0

**A small memory index that can be questioned against the actual conversation.**

`dsh-memory-dream` is a community-built memory bundle for DeepSeek Harness. It keeps a capped `MEMORY.md` index available to the agent, stores detail in dated notes and topic wikis, and gives the agent a `memory_dream` tool to collect conversation evidence for review. The agent—not the plugin—decides what to correct or leave unresolved.

## Highlights

- **Bounded, always-relevant memory:** `MEMORY.md` has a configurable character cap (default 4,000); updates can remove, revise and add entries in one batch.
- **Evidence-aware dream pass:** Review current memory against available session transcripts, dated notes and previous dream records.
- **Two kinds of dream output:** Append-only daily records and a revisable synthesis document.
- **Memory safety tools:** Heuristic injection scanner, `memory_audit`, status reporting, atomic file replacement and best-effort lock handling.
- **Release documentation:** English and Japanese READMEs, architecture diagram, full technical guides and contributor/security policies.
- **Workspace-bound transcript review:** When workspace restriction is enabled (the default), missing matching sessions do not trigger a search of other workspaces.

## Installation

From the GitHub source:

```bash
dsh plugin --profile web add github:Kaito-Rowing/dsh-memory-dream#v0.3.0
```

From npm **only after the published package has been verified**:

```bash
dsh plugin --profile web add dsh-memory-dream@0.3.0
```

Restart the profile and ask your DSH agent to run `memory_status`.

## Compatibility and caveats

- Node.js 20+ loads the bundle; Node.js 22.15+ is needed for zstd transcript reading.
- Prompt injection requires the DSH `systemPrompt` service. Other compositions can still use the tools.
- Transcript access and model prompts may expose private conversation text to your configured model provider. Do not publish memory or debug snapshots.
- The injection scanner and cross-process lock are best-effort mechanisms, **not** security guarantees.
- DeepSeek Harness is evolving rapidly; please report compatibility issues with a minimal redacted reproduction.
