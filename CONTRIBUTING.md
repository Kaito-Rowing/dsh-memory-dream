# Contributing

Thanks for helping improve dsh-memory-dream. This project is a community extension for DeepSeek Harness, not an official DeepSeek release.

## Before opening an issue

Check for similar reports. Include the DSH version, Node.js version, operating system, profile, expected/actual behavior, and the smallest reproduction you can share. **Never upload real memory files, raw transcripts, credentials, access tokens, or the private debug snapshot.** Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

## Development

Use Node.js 20 or newer; use Node.js 22.15+ (preferably 24) when testing compressed transcript reading.

```bash
git clone https://github.com/Kaito-Rowing/dsh-memory-dream.git
cd dsh-memory-dream
npm test
```

Tests use a local `@deepseek-ai/dsh-tools` stub generated by `test/setup.mjs`; do not commit generated dependencies. A local checkout can be installed using:

```bash
dsh plugin --profile web add link:/absolute/path/to/dsh-memory-dream
```

Restart the profile after installing. Run integration tests in a disposable DSH home, not one with real user memory. Run `npm test` before creating a PR.

## Pull requests

Keep changes focused, document user-facing behavior in both `README.md` and `README.ja.md`, and add regression tests for fixes. Explain compatibility implications, privacy effects, and how changes were validated. Do not claim manual DSH integration validation unless you actually performed it.

## Maintainer release checklist

- [ ] Audit open security/privacy blockers, especially cross-workspace transcript fallback and unsafe debug captures.
- [ ] Verify behavior against the intended DSH release and run `npm test` on supported Node versions.
- [ ] Confirm Node 20 gracefully degrades without zstd; test transcript support on Node 22.15+.
- [ ] Check installation and removal on a clean profile with non-sensitive fixtures.
- [ ] Verify `npm pack --dry-run` and that no logs, credentials, transcripts or generated files ship.
- [ ] Update both READMEs, `CHANGELOG.md`, the package version, and the version constant in `lib/index.js`.
- [ ] Review GitHub Actions status, create a version tag, and publish release notes only after checks pass.
- [ ] Publish to npm only if that is a deliberate, separately verified action.
